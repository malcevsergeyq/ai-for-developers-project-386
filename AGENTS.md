# AGENTS.md

Запись на звонок (Calendly-подобный сервис, «Календарь звонков»). Гость выбирает тип события и свободный слот и записывается без регистрации; владелец календаря (один заранее заданный профиль, авторизации нет) создаёт типы событий и смотрит список предстоящих встреч.

Контракт API — `spec/main.tsp` (TypeSpec, источник истины для фронта и бэка). `spec/openapi.yaml` из него **генерируется** — руками не править, перегенерировать через `npm run spec:build`. Статус проекта и план этапов — `PLAN.md`.

## Команды

- `npm install` — зависимости (Express 5, pg, cors; Vitest и supertest — dev)
- `npm start` — сервер на `PORT` (по умолчанию 3000). Без `DATABASE_URL` поднимается на хранилище в памяти и засевает два демо-типа встреч
- `npm test` — тесты (Vitest); БД не требуется, репозитории подменяются заглушкой
- `npm run lint` — ESLint (flat config, `eslint.config.js`); должен быть зелёным перед словом «готово»
- `npm run db:init` — накатить `server/schema.sql` через `psql "$DATABASE_URL"`
- `npm run spec:build` — перегенерировать `spec/openapi.yaml` из `spec/main.tsp`
- `npm run mock` — Prism поднимает мок бэкенда по контракту на `127.0.0.1:4010` (для разработки фронта без сервера)
- `cd ui && npm run dev` — фронт на `127.0.0.1:5173`; `npm run build` — сборка с проверкой типов; `npm run lint` — oxlint

**Базы данных сейчас нет.** Postgres не установлен, `psql` недоступен, `DATABASE_URL` не задан — `npm run db:init` выполнить нельзя, а `npm start` работает на памяти. `repositories/postgres.js` и `schema.sql` **ни разу не исполнялись против живой базы**: тесты идут на in-memory-хранилище и корректность SQL не подтверждают.

Механизма миграций нет. Когда база появится, правка `schema.sql` на уже накатанной базе потребует ручного `ALTER TABLE`.

Фронт и бэк работают вместе: `npm start` в корне и `npm run dev` в `ui/`. Мок Prism (`npm run mock`) больше не нужен для разработки, остаётся как способ проверить, что вообще разрешает контракт.

## Стек

- Бэк: Node + Express — `server/`
- Хранилище: два репозитория за одним интерфейсом. Есть `DATABASE_URL` → PostgreSQL (`repositories/postgres.js`), нет → память (`repositories/memory.js`). Выбор делает `server/index.js`. Это не запасной путь: проверка Hexlet собирает только `Dockerfile` и запускает контейнер, базы там нет
- Фронт: React 19 + TypeScript + Vite — `ui/`; UI на shadcn/ui (стиль `base-nova`: Base UI + Tailwind v4), роутинг `react-router-dom`. Отдельный процесс и деплой от бэка

## Структура

- `server/` — Express-приложение. Раскладка: `routes/` (HTTP: `public.routes.js`, `admin.routes.js`) → `services/` (правила) → `repositories/` (`memory.js` и `postgres.js` за одним интерфейсом), плюс `mappers/dto.js` (домен → тело ответа), `time.js` (окно записи и сетка) и `errors.js`. `createApp` принимает репозитории аргументом — поэтому тесты идут без Postgres
- `spec/` — контракт: `main.tsp` (пишем руками), `openapi.yaml` (генерируется), `tspconfig.yaml`
- `ui/` — фронт: `api/` (сгенерированные типы + клиент), `pages/` (экраны гостя и владельца), `components/ui/` (вендорные компоненты shadcn, правятся только его CLI), `hooks/`, `lib/`
- `PLAN.md` — статус этапов, принятые решения

## Конвенции

- Все конвенции API (состав DTO, коды ошибок, формат дат/времени) — см. `spec/main.tsp`, здесь не дублируются
- Перед реализацией нового DTO/эндпоинта — сверяться с `spec/main.tsp` и переиспользовать описанные там модели; не создавать параллельные структуры данных без явной необходимости
- Всё время — UTC, ISO 8601. Таймзон в приложении нет
- Слоты не хранятся, а вычисляются: сетка стартов 30 минут, 09:00–18:00 UTC, только будни, окно 14 дней от текущего момента
- Бронь занимает `[start, start + durationMinutes)`. Слот занят, если интервалы пересекаются, — пересечение, а не совпадение точки старта
- Занятость глобальная: пересекающиеся брони запрещены и для разных типов событий. Проверку делает хранилище, а не сервис — в памяти синхронно перед вставкой, в Postgres exclusion-ограничением `bookings_no_overlap`. `SELECT` перед `INSERT` оставил бы окно для гонки
- Репозитории отдают доменные объекты с `Date`, а не строки: ISO появляется только в `mappers/dto.js`. Иначе форматирование разъедется между двумя реализациями хранилища
- Время в сервисы приходит аргументом (`now`), а не берётся из `Date.now()` внутри: слоты зависят от момента, и тест, привязанный ко дню прогона, начал бы падать в выходные
- Ошибки — телом `{error, message}`; коды перечислены в спеке (`validation_failed`, `event_type_not_found`, `slot_unavailable`)
- Типы API на фронте **не пишутся руками**: `ui/src/api/schema.d.ts` генерируется из контракта командой `npx openapi-typescript@7 ../spec/openapi.yaml -o src/api/schema.d.ts` (запускать из `ui/`). Поменял контракт — перегенерируй, иначе расхождение всплывёт у пользователя, а не у компилятора
- Адреса в деве — `127.0.0.1`, не `localhost`: Prism слушает IPv4, а на Windows `localhost` резолвится в `::1`
- `ui/src/components/ui/**` — вендорный код shadcn, из линтера исключён; свои компоненты кладутся рядом, а не внутрь
- Бэк и фронт — разные origin (раздельный деплой), на сервере нужен явный CORS
- UI — на русском
